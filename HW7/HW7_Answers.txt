1. Familiarize yourself with the code. Determine how to modify each of the following parameters, 
and explain what changing those parameters will do:
	- The number of hidden layers and the size of each layer
	- The number of epochs and the learning rate
	- The batch size

    The hidden layers are basically a layers of nodes that have certain wieghts that determine 
    how important certian inputs. These weights change as they are trained. The size of each layer
    determines how many nodes each layer has. The larger the model, more more likely it can memorize
    state-action pairs and overfit itself to the traingin data.

    Typically 2 hidden layers can learn any non-linear function. 

    The epoch is a part of training the model, it pretty much tells you how long to train for.

    The learning rate tells us how much we can update the model wieghts by. Larger Learning rates 
    can let you learn faster, but you might not be able to converge on a good solutions
