Increasing the batch size and number of epochs (training time) helped somewhat, but increasing
the learning rate made a dramatic difference. The results jumped from 55% success to nearly 90%.

This might be because increasing the initial learning rate improves exploration at the start,
and then Adam gradually tunes that learning rate down during training, allowing it to learn a
well-generalized policy.

Upsampling is basically when you take a dataset and add to it by slightly modifying the
existing data.

Our upsampling method adds noise to the states and actions, creating samples that guide the
model back toward the original state-action pairs, as if it were correcting noisy behavior.

This "700_50_0.01_64_upsampled_datasetwhistory_weights" set performed very well. Here's what I did:
I took the regular dataset with history and upsampled it using data with 0.025 m of variance.

The resulting dataset was trained for 700 epochs with a batch size of 50 and a learning rate
of 0.01, using a model with a 64x3 hidden-layer network.
